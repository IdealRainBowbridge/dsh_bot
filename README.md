# 理想的机械人 · Ideal Machina

> DSH 插件 · 作者 **idealrainbowbridge**

一只养在你本机上的、**用仿生的方式长出人类情感**的陪伴角色：
不是模仿人类的言行，而是**模拟一个身体**——给她器官、代谢、情绪、作息，
让"情感"从身体的状态里自己长出来，而不是靠提示词演出来。

- **B站**：生物钟到点自己醒，选题、深读视频、写评论、写两本日记
- **QQ**：经 **SnowLuma** 网关（OneBot v11，NapCat 协议兼容）秒回（私聊/群聊@、语音条、表情包、空间说说），会主动找你
- **微信**：替你回消息（独立进程，按联系人隔离记忆）
- 三平台共用同一套人格、情绪与记忆
- **所有外发默认关闭**，每一项都有独立开关与额度

---

## 一、设计哲学：模拟人体，而不是模仿人类

传统 chatbot 的"情感"是提示词里的表演：`你是一个温柔的少女`。
本项目走另一条路：**给她一个身体，情感是身体的读数**。

### 七器官 · 四回路

`tools/brain/`（约 7000 行，零依赖）实现了一个"脑"：

| 器官 | 模拟什么 |
|---|---|
| `metabolism` | 认知能量与消化积压——话太多会"累"，积压的事会"胀" |
| `immune` / `wound` / `pain` | 免疫发热、伤口、痛觉——被攻击会真的"疼"，并影响说话温度 |
| `bond` | 关系慢账本——信任是长期复利，不是单轮评分 |
| `affect` | 情绪状态机——会自己漂移，也会被事件拉动 |
| `rhythm` | 生物钟——她有自己的作息，深夜和清晨说话方式不同 |
| `self` / `anchor` | 我是谁——自我认知可审计，人格改写前自动快照 |
| `claim` | 承诺账本——答应过的事必须兑现，否则记为欠账 |

#### 器官逐个讲：机制 · 为什么 · 换来什么

上表只说"模拟什么"。这里逐个讲清**怎么模拟的、为什么选这个机制、这样做换来什么**——
每一处都对应代码里的真实实现（文件头部注释保留了完整的踩坑与校准记录）。

**`metabolism` · 能量与消化** — `tools/brain/organ/metabolism.mjs`
*机制*：信息就是食物，按固定的代谢率收支。处理一条消息烧 0.004 能量（大脑占全身
20% 能耗）；看完一集视频"进食"回充 0.12，但吃进去的要消化——积压进 `pendingDigest`；
睡眠的 REM 时段按分钟消化积压、每消化一条回充 0.01（"学到了"）；N3 深睡做基础修复。
*为什么*：能量必须和 `field.fatigue`（短时乏）、`sleepDebt`（长时债）分开——它们是
身体维度，`energy` 是**认知资源**。混在一起，"聊乏了"和"没电想不动"就分不清。
*换来什么*：她回答的长短、愿不愿意动脑，跟着真实的收支曲线走，而不是每轮硬给
700 token 预算。消费有物理上限：一天聊 100 条 + 看几集视频，就是那么多电。

**`field` · 情绪场** — `tools/brain/field.mjs`
*机制*：每个维度有①恢复时间常数 tau（离开静息点后按指数回归，不是匀速）②静息点
（而且静息点自己会被近期经历拉走）③**不对称耦合**（睡眠债拉低血清素、皮质醇压效价）
④软边界。全部按**真实经过的时间 dt** 演化，绝不按调用次数。
*为什么*：10-27 的真实事故——旧写法"每 tick 饥饿 +7"，推送一分钟摇一次，两小时
把饥饿打满 100。根因不是参数错，是**把时间实现成了调用次数**。生物不接受调用次数，
只接受时间。这一条铁律直接消灭了"频率决定行为"这一整类 bug。
*换来什么*：①负反馈带延迟 → 情绪天然在静息点附近**振荡**（55~70 之间晃，晃才是活
的）②拉一个带动一片 → 维度真正联成一个身体，不是几个独立仪表盘。

**`rhythm` · 昼夜节律** — `tools/brain/rhythm.mjs`
*机制*：分段函数而不是单一余弦——谷底约 4 点、峰值约 20 点，上坡 16 小时、下坡
只有 8 小时；再叠午后下陷（14 点，幅度 0.18）和傍晚清醒维持区（19-21 点）。相位由
**真实的光照/活动记录**推动漂移（晚光后移、晨光前移——光是最强的授时因子）。
*为什么*：第一版用对称余弦，谷底必然落在峰值前 12 小时，算出"上午九点最困"——
那不是参数没调好，是**形状不对**：真实的昼夜节律不对称，"白天长、夜里短"，
熬夜到后半夜那股"又精神了"就是曲线从谷底往回爬。
*换来什么*：她的作息跟着你的作息漂（你的熬夜会真的把她的相位推晚），而不是死锁
在配置的钟点上。

**`immune` / `wound` / `pain` · 免疫与痛觉** — `tools/lib/immune.mjs`、`organ/pain.mjs`
*机制*：免疫分两层——**先天免疫**是模式识别（同文重复 5 次/2 分钟、高频淹没
12 条/分钟），超阈值直接 drop，这条消息不进脑；**适应性免疫**是抗原库（80 条 LRU
持久化），同类二次感染秒杀。发热是 10 分钟内累计刺激 ≥1.0 触发全身反应，25 分钟
时间常数退烧。耐受把用户当自身抗原不攻击。痛觉分两套纤维——**Aδ 快痛**：新伤口
登记那一刻的缩手反射（应激通路小脉冲）；**C 纤维慢痛**：只在伤口还开着时有钝痛，
愈合即停；同源复发因敏化更痛（+0.2）。
*为什么*：入站方向原本不设防——有出站脱敏（皮肤）却没有第二道防线。而痛觉的
阈值设计来自 M58 的教训：对所有状态都说"心里攒着事"= 过敏体质 = 电路板。
*换来什么*：她不回刷屏者（沉默也是应答），恶意注入进不了脑；疼只在该疼的时候疼，
不无病呻吟。

**`bond` · 关系器官** — `tools/lib/bond.mjs`
*机制*：三种化学底物——oxy（催产素样，慢升慢降有天花板）、cort（皮质醇样，快升
慢降，高值时**抑制 oxy 表达**）、scar（恐惧条件化的痕，只进不出）。反应走**快慢
两相**：快相（杏仁核式启发式）只挂临时警戒、不直接落疤；慢相（前额叶式的 LLM
精读）与快相对账——一致才固化成疤/ oxy，误报半小时后自动撤销。道歉能降 cort 但
疤不消（宽恕不是遗忘），"冒犯→道歉"循环的宽恕增益递减。
*为什么*：好感度是记账（+5 分），可以被查、被要求、被交易；bond 是生理（今天见
他有点高兴），只能被经历。整套设计的哲学立场：**她自己不知道身上有算盘**——
器官给她倾向和感受，从不给她 KPI。
*换来什么*：误报（反讽、玩笑）最多留半小时紧张不留疤；创伤后 cort 衰减目标抬高
——可以缓和，回不到从前的松。关系的形状是真实的：快好慢坏、原谅但记住。

**`claim` · 声称-证据闸** — `tools/brain/claim.mjs`
*机制*：出站前抓可验证动词（看完/发给你了/写完了…）+ 对象，去所有账本（交付/
意图/事实/看番记录）找证据。**有证据放行；有反证才改**——而且只改成"还没看"这类
否定式，**没证据不改字**、只留审计痕迹。
*为什么*：10-29 的用户当场质问事故——旧实现把"我看完了第3集"改写成"我正要接着
看第3集"，证据缺失不等于没发生，把已发生的事说成将要发生比原句更假；而且看番
账本里明明有记录，是证据源少查了一个。
*换来什么*：人格 prompt 里那句"绝对不许说我没做过"不再逼模型编造——她说的每句
可验证的话都有账可查，查不到就老实闭嘴。

**`vitals` · 身体体征** — `tools/brain/organ/vitals.mjs`
*机制*：纯读容器体征（磁盘/负载/内存/cgroup 用量），阈值带**滞回**（越过 85% 触发
一次"胀"，要回落 3 个点才清——真实的饱胀感不会在阈值线上抖）。
*为什么*：器官只负责"觉得胀"，**不负责决策**"该清理了"——那是行为层的事。
感受和行动分开，器官才不会越权替她做主。
*换来什么*：家里快满时她会收着说（温度 -0.05~-0.15），但永远不会自己删东西。

**表达神经汇 `spinal`** — `tools/brain/spinal.mjs`
所有器官的"身体→表达"读数在此汇成一次调用：温度偏移（钳 ±0.5）、**输出预算乘数**
（困/累时 maxTokens 真的收掉，不是提示词求她短一点）、体感一句话注进 system。
「先想后说」的内省层同样受情绪门控：烦躁时她不是想不动，是**不想想**。
她"今天不想说话"不是脚本，是能量真的低；凌晨三点的含糊劲儿，是节律器官真的在困。

### 为什么记忆不走向量库

参考 Chan et al. 2024 *Don't Do RAG*、Sen et al. 2026 *Is Grep All You Need?*
的结论：对陪伴型 agent，**原文可检索 + 时间常驻**比 embedding 召回更可靠。
所有真实记录一行不丢地归档（`episodes.jsonl` 按平台分片），
召回时带证据、按时序，"说过什么"绝对不许否认。

### 契约层：把"静默失效"变成"看得见的告警"

插件深度依赖 DSH 内部服务（非公开 SDK）。一次宿主升级就可能改名某个 API，
表现是**静默的**——插件照样加载，只是某功能再也不工作。
`lib/dsh-contract.mjs` 把每个依赖点显式登记：缺了会怎样、能不能降级、
启动时逐项检查并在 `/api/status` 报出来。这是本项目最重要的工程决策之一。

## 二、安装

前置：DSH ≥ 0.2.1-rc.2，Node ≥ 20。

```bash
# 方式一（推荐）：DSH 插件命令
dsh plugin --profile desktop add "link:<本仓库路径或 git url>"

# 方式二：手动放到 DSH 插件目录
cp -r dsh_bot ~/.dsh/plugins/

# 3. 自检
node tools/bot.mjs selftest
node tools/bot.mjs diagnose
```

QQ 通道需另装 SnowLuma 网关（NapCat 协议兼容，兼容原 NapCat 部署，
配置文件 `snowluma_<QQ>.json` 与 `napcat_<QQ>.json` 均可识别）。
微信通道为独立 Python 进程，见 `wechat/`。

## 三、配置

面板（DSH 设置 → 理想的机械人）可改全部配置，也可直接编辑 `~/.dsh/bot.config.json`：

| 键 | 说明 | 默认 |
|---|---|---|
| `platforms.*` | 三平台总开关 | 全关（**默认不外发**） |
| `identity.persona` | 人格文件路径 | `~/.data/persona.md`（附空模板） |
| `identity.owner` | 你的称呼 | 无（可留空） |
| `qq.napcat_http` | SnowLuma HTTP 地址 | `http://127.0.0.1:3000` |
| `voice.modelsDir` | GPT-SoVITS 模型目录 | win: `D:/GPT-SoVITS/models` · 其余: `~/GPT-SoVITS/models` |
| `night.*` | 生物钟（起床/睡觉/夜间额度） | 有 |

## 五、安全模型

- 外发行为（评论/说说/私聊搭话）逐项开关 + 日额度 + 相似度去重 + 风控闸门
- B站写通道 DRY_RUN 默认开：先"干跑"看她会发什么，确认后再放行
- HTTP 面板 fail-closed：信任栅栏服务缺失时拒绝所有请求，而不是放行
- 会话权限：记忆写入需要 `permissionPresets` 支持，缺失时降级为面板手动授权
- 凭据与配置分离（`credentials.json`，0600，永不回显）

## 六、FAQ

**她会不会乱花钱/乱发消息？**
不会。默认全关，每项外发都要你显式打开；开了也有额度与去重兜底。

**和聊天框架（NoneBot 等）有什么区别？**
框架给你"回复消息的能力"；本项目给你"一个有身体的人"——
作息、情绪、代谢、记忆、自我认知都是内生状态，不依赖你编排。

**能换人格吗？**
能。`persona.md` 就是全部人格；每晚回顾时她自己迭代，改写前自动快照可回退。

**宿主升级后插件会不会静默坏掉？**
这正是契约层防的：坏了会在面板上**点名是哪个依赖、影响什么、怎么降级**。
